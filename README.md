# Australian Labradoodle Handbuch

Ein interaktives, deutschsprachiges Nachschlagewerk für die ersten Wochen mit einem 8–9 Wochen alten Australian-Labradoodle-Welpen.

## Funktionen

- Schnellsuche über alle Kapitel
- Themen-Navigation für Ankunft, Fütterung, Schlaf, Training, Stubenreinheit, Sozialisation, Pflege und Gesundheit
- Interaktive Tages- und Einzugschecklisten
- Eigener Abschnitt zum Crate Training
- Mobilfreundlich und ohne Build-Schritt

## Lokal starten

Die Dateien können direkt im Browser geöffnet werden. Für einen lokalen Webserver:

```bash
python3 -m http.server 8000
```

Danach `http://localhost:8000` öffnen.

## GitHub Pages

Unter **Settings → Pages** als Quelle `Deploy from a branch` auswählen und den Branch `main` mit dem Ordner `/ (root)` veröffentlichen.

## Hinweis

Dieses Handbuch ersetzt keine tierärztliche Untersuchung oder individuelle Beratung. Impf-, Entwurmungs-, Ernährungs- und Behandlungspläne gehören mit einer Tierärztin oder einem Tierarzt abgestimmt.
